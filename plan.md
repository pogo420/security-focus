## Week wise plan

Week | Topic(s) | Hands-on
-- | -- | --
1 | Networking for Security (TCP/IP, DNS, HTTP, HTTPS) | Capture traffic with Wireshark 
2 | Linux Security Basics & Permissions | Practice users, groups, sudo, file permissions
3 | HTTP Deep Dive & REST Security | Inspect requests with browser DevTools
4 | Burp Suite Community | Intercept and modify HTTP requests
5 | OWASP Top 10 – Part 1 (Broken Access Control, Injection) | PortSwigger labs
6 | OWASP Top 10 – Part 2 (XSS, CSRF) | Solve XSS & CSRF labs
7 | Authentication & Authorization (Sessions, JWT, OAuth Basics) | Secure a sample FastAPI app
8 | API Security (OWASP API Top 10) | Test APIs using Burp/Postman
9 | Secure Coding in Python | Fix insecure Python code examples
10 | Secrets Management & Cryptography Basics | Hash passwords, manage secrets securely
11 | Docker Internals (Namespaces, Cgroups, Layers) | Explore image layers and containers
12 | Docker Security Best Practices | Harden one of your Dockerfiles
13 | Container Image Scanning (Trivy, Grype, Docker Scout) | Scan your own images
14 | SBOM & Supply Chain Security | Generate SBOM using Syft/CycloneDX
15 | Image Signing (Cosign) | Sign and verify container images
16 | Kubernetes Security Fundamentals | Review K3s security configuration
17 | RBAC & Service Accounts | Create least-privilege roles
18 | Pod Security & Security Contexts | Restrict privileged containers
19 | Network Policies & Kubernetes Secrets | Isolate workloads with NetworkPolicies
20 | Kubernetes Security Tools (Kubescape, kube-bench, Falco) | Scan your cluster
21 | CI/CD Security (GitHub Actions, Jenkins) | Add security scanning to a pipeline
22 | SAST, Dependency Scanning & License Checks | Integrate Semgrep and Trivy
23 | Threat Modeling (STRIDE) & Secure SDLC | Threat-model one of your applications
24 | Final Project: Secure End-to-End Platform | Build a complete secure deployment pipeline
